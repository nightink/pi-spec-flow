## Repair and coverage

The previous root Type.Union is legal general JSON Schema but produces anyOf without root type. The model carries the entire tool list, so a declaration fault can reject a request intended for a different tool before execution. The actual Anthropic legacy converter instead forces object with properties={}, losing the union branches. Flat closed Type.Object fixes both; same tool name and fields, nested action/mode enums and default prepare. No tool splitting, root composition, field filtering or hidden retry.

Shared engine is byte-unchanged. It keeps exact prepare/run/status field allowlists and required identifiers. Core negative cases retain a **disposable synthetic grant** at used=0 with byte-identical job/Spec/budget and no fake-executor marker. Actual native negatives include missing jobId, invalid ID/action/mode, unknown keys and prepare-only/run-only fields on the wrong action; they neither alter the prepared job nor create another job/grant. These tests are not real model review or live executor replay.

Source binding also proves core, review-engine, review-execution, storage, worker and adapter-core unchanged, plus index.ts byte-unchanged outside the review declaration. Thus the S1.2 presentation/confirmation fix and S1.7 launch/charge policies are retained, with their actual regressions rerun.
