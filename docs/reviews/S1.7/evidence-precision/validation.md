## 为什么经历多轮

7次调用并非7次实现复审，而是4次真实盲测和3次独立审查。格式收敛涉及 criterion 分层及历史 finding ID 命名空间；独立审查另发现协议降级漏洞，以及防降级修复新引入的 v3 scope/status 兼容回归。二者均先红后绿修复并获得后续独立确认。维护范围和归档复杂度扩大了交付成本，不把这一成本包装成产品准确率提升的证明。

## 公开边界

公开导出保留被验收的运行、测试、合成数据、模板和 skill 字节；仅维护状态行补记此次发布。全部93份施工证据文件不进入公开提交，改为本目录摘要和源码清单。原件及旧提交仍私有保留；不修改原始 hash、FAIL 或审批历史。

公开提交直接基于已公开上游构建，不携带旧未推施工提交的祖先历史，不 force-push。发布前在导出工作树重新运行完整门禁和 Pi smoke，并扫描实际公开树及新增提交内容。公开摘要不替代私有原文核验；没有施工前独立提案批准，不补造。

Node22、生产浏览器、远端 CI、独立时间认证、真实人工签名与实际账单未在此认证。调用方产品和全局 skill 均未修改或安装。
